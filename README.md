# Crypts of Shadow

A dungeon-crawling adventure through dark crypts filled with danger and mystery.

## 🎮 Overview

Crypts of Shadow is a dungeon crawler built with Swift and SceneKit. Delve into procedurally generated crypts, battle enemies, collect loot, and survive the depths in this atmospheric action-RPG.

## ✨ Features

- **Dungeon Crawling**: Explore dark, atmospheric crypts
- **Procedural Generation**: Unique dungeons every playthrough
- **Combat System**: Real-time action combat
- **Loot & Progression**: Collect items and grow stronger
- **3D Graphics**: SceneKit-powered visuals
- **Dark Fantasy**: Gothic horror aesthetic

## 🛠️ Tech Stack

- **Language**: Swift
- **3D Engine**: SceneKit
- **UI**: SpriteKit
- **Platform**: macOS

## 🚀 Getting Started

### Prerequisites
- macOS 10.15 or later
- Xcode 13.0 or later

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kevmart15/crypts-of-shadow.git
cd crypts-of-shadow
```

2. Compile and run:
```bash
swiftc main.swift -o crypts-of-shadow -framework AppKit -framework SceneKit -framework SpriteKit
./crypts-of-shadow
```

## 🎯 Gameplay

- Explore procedurally generated crypts
- Battle undead and monsters
- Collect treasure and equipment
- Progress through deeper levels
- Survive the darkness
